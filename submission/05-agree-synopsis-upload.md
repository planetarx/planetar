# Field 05 — Synopsis upload not-evaluated acknowledgement

**Form section:** Component 1a → 2 - Project Description → A
**Field label:** *"By checking this box, you understand that any document uploaded to support the synopsis will not be considered for evaluation purposes."*
**Type:** Radio: `I Agree` / `I Do Not Agree`
**Status:** ✅ READY

## Select

**`I Agree`**

## Why

- The form allows a 1-page PDF/JPEG synopsis upload but explicitly says it won't be evaluated. So whatever you upload there is decorative (a teaser slide, a diagram).
- Saying "I Do Not Agree" probably blocks form progress.
- Recommendation: **don't upload anything** for the synopsis. The text synopsis (Field 03) does the work. An evaluator's first impression should be the prose, not a hastily-made slide.
